# Experiments

Generated by `training/train.py`. Do not edit by hand.

**Data:** IBM Telco customer churn sample, 7,043 customers, 26.5% churned. This is a fictional sample dataset, so the numbers show the method and not a real business.

**Cleaning:** `TotalCharges` arrives as text. 11 blanks all belong to customers in their first month, so they become 0. A blank for any other customer stops training. `customerID` and `gender` are not used as features.

**Method:** 80/20 stratified split, done first. Scaling and encoding live inside the pipeline, so they are fit on training data only. The model is chosen with 5-fold cross-validation on the training set, and the test set is scored once.

## Model choice (5-fold cross-validation, training set)

| Model | ROC AUC | PR AUC | F1 at 0.5 | Largest difference after ONNX export |
|---|---:|---:|---:|---:|
| Gradient Boosting | 0.847 | 0.665 | 0.590 | 2.0e-01 |
| Logistic Regression | 0.846 | 0.658 | 0.595 | 1.4e-07 |
| Random Forest | 0.844 | 0.655 | 0.573 | 2.7e-02 |

Chosen: **Logistic Regression**, the highest ROC AUC among models whose ONNX export stays within 0.001 of the trained model, measured in cross-validation on customers it did not train on. A model that changes when exported is not the model that was evaluated, so it is not eligible, even if it scores slightly higher.
